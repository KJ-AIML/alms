## Design rules (locked for future execution)

1. **Caller cancellation ≠ provider stopped.** Record client action separately from any
   provider-side evidence of cessation (Q-002).
2. **Retries measured, not inferred.** Count outbound attempts / model requests.
3. **No fake coverage.** If a lane cannot use the common fault-server, mark
   UNSUPPORTED / INCONCLUSIVE with reason — do not claim parity.
4. **OpenRouter / custom base_url** must not substitute for native stress evidence.
5. **L-01** remains F2/proposed; LiteLLM TOOL stress must not silently pull Proxy deps.
