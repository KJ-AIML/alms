`harness/src/alms_audit/invariants/` implements DevSpec Section 44 / P0-020: deterministic,

## Evaluators implemented

| Key | Behavior summary |
|---|---|
| `usage_not_fabricated` | Absent provenance requires null token fields; non-null tokens forbid absent provenance |
| `terminal_state_present` | `observed_terminal_state`, `response_completed`, or ERROR/BLOCKED/UNSUPPORTED status |
| `non_empty_assistant_content` | Non-empty `text_delta` / structured output, or exempt error/blocked/unsupported status |
| `expected_tool_name` | Matching `tool_call_completed`, deferred approval, or requires_action extension |
| `expected_tool_arguments` | JSON subset equality on parsed tool arguments |
| `tool_call_count` | Count of `tool_call_completed` (+ deferred extension surplus) |
| `schema_valid` | Structured fixture requires `structured_output_completed`, schema note, or soft STR PASS |
| `expected_fields_equal` | Subset field match on structured `parsed` output |
| `stream_has_monotonic_sequence` | Monotonic `sequence` when streaming; else started before completed |
| `error_category_present` | ERROR fixtures / `ERROR_RUNTIME` require error event or category |

Any other `expected_invariants` key in the committed corpus returns
`mode=manual_review`, `passed=null`, `detail=pending evaluator`.

## API

```python
from alms_audit.invariants import evaluate_invariants

results = evaluate_invariants(fixture_data, result_data, transcript_data)
# [{"name": "...", "passed": True|False|None, "detail": "...", "mode": "deterministic"|"manual_review"}, ...]
```

Evaluation iterates `fixture_data["expected_invariants"]` keys in sorted order.
