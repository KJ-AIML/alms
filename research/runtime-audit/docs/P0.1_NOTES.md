# P0.1 — Schemas + Harness Foundation

## What this slice establishes

The audit lab's internal **data contracts** and a minimal harness that loads and
validates them. Everything here is **research/audit infrastructure only**. None of it is
the future ALMS Runtime Contract, and the Probe Process Protocol v0 is explicitly not the
future `ModelRuntime`.

### Evidence schemas (`spec/`, JSON Schema draft 2020-12)

| Schema | DevSpec | Role |
|---|---|---|
| `fixture.schema.json` | Section 27 and Section 28 | Language-neutral case: intent, execution controls, expected invariants |
| `probe-request.schema.json` | Section 41 | The one JSON message the harness sends a probe subprocess |
| `probe-response.schema.json` | Section 30 | Raw run manifest a probe returns — what happened, with raw-artifact paths |
| `normalized-transcript.schema.json` | Section 31 | Audit comparison transcript; every event points back to raw |
| `result.schema.json` | Section 34 and Section 17 and Section 32 | One record per fixture × lane; primary status + provenance-aware usage |
| `finding.schema.json` | Section 36 and Section 18 | Findings with F0–F4 severity; require human (KJ) review |
| `run-manifest.schema.json` | Section 35 | Immutable per-run manifest; credential *presence* booleans only |

### Harness (`harness/`, package `alms_audit`)

- `schemas.py` — locate/load/validate against `spec/*.schema.json` (uses `jsonschema`).
- `fixtures.py` — discover `fixtures/**/*.json`.
- `lanes.py` — load `configs/lanes.json` (7 canonical lanes; Section 29 and Section 47).
- `cli.py` — `alms-audit validate | list-fixtures | list-lanes` (read-only, no network).
- Own `pyproject.toml` + `uv.lock`. Only dependency is `jsonschema`. **No runtime SDKs**
  (DevSpec Section 20 and Section 25); a test asserts none are importable.

## Required properties encoded (with where)

| Principle | Encoded as |
|---|---|
| Raw Evidence != Normalized Interpretation | `normalized-transcript`: `raw_ref` **required** per event; `raw_manifest` required. Test: `test_transcript_event_requires_raw_ref`. |
| Probe Process Protocol v0 != Future ModelRuntime Contract | `$comment` in `probe-request`/`probe-response`; package + README statements. |
| Unsupported != Failed | `result.status` enum keeps `UNSUPPORTED_DECLARED`/`UNSUPPORTED_OBSERVED`/`BLOCKED_CONFIGURATION`/`FAIL_INVARIANT`/`ERROR_RUNTIME` distinct. Test: `test_result_status_enum_distinguishes_outcomes`. |
| Missing usage != Zero usage | `result.usage` token fields nullable; `provenance`/`finality` enums. Test: `test_result_usage_missing_is_null_not_zero`. |
| Local cancellation != Provider definitely stopped | `probe-response.timeout_or_cancellation_action` `$comment` marks it client-side only; `cancelled` transcript event carries `raw_ref`. |
| Schema-valid output != Native structured output | `fixture` `$comment` on `output_schema`; distinct `schema_valid` vs native-mode invariants named in Section 44. |

## Explicit non-goals (honored)

No `ModelRuntime`/`AgentRuntime`/`WorkflowRuntime`; no runtime probes; no provider SDKs;
no LangChain→adapter migration; no ALMS-core refactor; no production-source edits outside
`research/runtime-audit/`; no network calls; no API keys.
