# Q-005 Embedding Scope — Evidence-Backed Deferral

Status: offline decision input only. No live provider request was made during
P0.9-q005-deferral. No EmbeddingRuntime implementation was begun. Phase 0 remains
open. P0.8 Stress Semantics and Draft ModelRuntime remain unauthorized.

Authority: Bible Q-005 / ADR-005 (PROVISIONAL); DevSpec Section 101 Q-005; EXIT-12;
assumption A-007; fixture EMBED-001; P0.7C exit-gap assessment.

## Decision

**Defer EmbeddingRuntime** out of Phase 0 ModelRuntime / first-alpha generation surface.

Recommended destination: a **sibling `EmbeddingRuntime` DevSpec** after Phase 0 exit
(or later alpha), not as a required cell of the Phase 0 six-lane generation matrix.

This is an **explicit evidence-backed deferral**, not a recommendation to include
EmbeddingRuntime in the first alpha.

## Evidence basis (offline)

| Evidence | Finding |
| --- | --- |
| Fixture corpus | `EMBED-001` is OPTIONAL tier; `live_required: true`; `supports_mock_mode: false` |
| Six-lane matrix | GEN/ROLE/STR/TOOL/STREAM/USAGE only — embeddings are not in the mandatory six-fixture set |
| Assumption A-007 | Still `open`: “Embeddings should ship as a sibling contract in the first alpha” |
| ADR-005 | PROVISIONAL: embeddings probed separately; may be excluded from first alpha |
| First-live plan | P0.4C / P0.7C exclude EMBED-001 from Tranche A/B |
| Offline mock | No embedding lane offline simulation exists; EMBED-001 cannot be exercised offline |

## Why deferral (not inclusion)

1. **Insufficient cross-runtime evidence.** No live embedding run exists; no offline mock path.
2. **Lifecycle incompatibility risk.** Embedding semantics (vector shape, dimensions, usage)
   are separate from generation invariants; folding them into ModelRuntime v0 would invent
   contract surface without Phase 0 evidence.
3. **Exit gate wording.** EXIT-12 allows “recommendation complete **or** explicit
   evidence-backed deferral.” This document is the latter.
4. **Does not block generation audit.** G2/G3/G4 offline work and live core tranches remain
   generation-focused.

## What this does *not* decide

- It does **not** falsify A-007 live (status remains `open` until live EMBED-001 or a later
  explicit assumption update).
- It does **not** claim embeddings have low product value.
- It does **not** authorize an embeddings live tranche in this slice.
- It does **not** close Phase 0 or authorize P0.8 / ModelRuntime.
