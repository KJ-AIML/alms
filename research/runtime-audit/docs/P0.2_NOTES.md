# P0.2 — Planner, Budget, Runner, and Evidence Storage

## What this slice establishes

The offline safety machinery that must exist **before** any live probe: configuration
loading, matrix planning, a fail-closed budget guard, a subprocess runner with timeout,
raw-artifact redaction, and immutable run-manifest creation. Still no live calls, no
credentials, no provider SDKs. Dry-run is the default.

### Modules (`harness/src/alms_audit/`)

| Module | DevSpec | Role |
|---|---|---|
| `config.py` | Section 80 | Load `configs/audit.default.toml` (stdlib tomllib) into `AuditConfig` |
| `planner.py` | Sections 39, 45 | Build the fixture x lane matrix; every skip carries a reason; expected call count |
| `budget.py` | Section 80 | `check_live_budget` (fails closed when hard cap absent/non-positive) + `check_call_cap` |
| `redaction.py` | Section 85 | Mask API keys, Authorization/Bearer, cookies, signed-URL signatures, configured secret values; preserve benign evidence |
| `environment.py` | Sections 35, 83, 86 | OS/Python/uv/git capture, lock + fixture-corpus hashes, credential PRESENCE booleans only |
| `protocol.py` | Section 23 | Build a probe-request (Probe Process Protocol v0 — provisional, not the runtime contract) |
| `subprocess_runner.py` | Section 41 | Invoke a probe with timeout; capture stdout/stderr/exit/duration; preserve diagnostics on failure/timeout |
| `storage.py` | Sections 30, 35, 46 | Prepare `runs/<id>/`, atomic writes, schema-validated immutable run manifest |
| `runner.py` | Sections 37, 40 | Orchestrate: plan -> preflight gates -> dry-run manifest; live refused without confirm + budget |

### CLI additions

- `alms-audit plan` — previews selected fixtures/lanes, expected call count, skipped
  cases with reasons, missing credentials, budget, tokens, timeout. Makes no calls.
- `alms-audit run` — dry-run by default; writes a validated run manifest + `plan.json`
  into the gitignored `runs/<id>/`. Live requires `--live --confirm-live` and a budget.

## Safety properties (with where enforced)

| Property | Enforcement | Test |
|---|---|---|
| Live run without budget is refused | `budget.check_live_budget` fails closed on null/0/negative hard cap | `test_live_budget_absent_or_nonpositive_is_refused`, `test_live_without_budget_is_refused` |
| Live run without `--confirm-live` is refused | `runner.run` raises before any execution | `test_live_without_confirm_is_refused`, CLI `test_run_live_without_confirm_is_refused` |
| Dry-run is the default | `runner.run(live=False)` path; no calls, no subprocess | `test_dry_run_is_default_and_writes_valid_manifest` |
| Subprocess timeout works | `subprocess_runner.run_probe` kills child, records `TIMEOUT_EXIT` | `test_subprocess_timeout_is_enforced` |
| Failed runs preserve diagnostics | stdout/stderr always written to `raw/` | `test_failed_run_preserves_diagnostics` |
| Secret redaction | `redaction.redact` | `test_redaction.py` (6 cases) |
| Missing usage != zero; unsupported != failed; raw != normalized | preserved from P0.1 schemas | P0.1 tests |
| Manifest never contains secrets | run-manifest `additionalProperties:false`; credential presence booleans only | `test_run_manifest_rejects_unknown_field` |

## Deliberate simplifications

- Lane definitions stay in `configs/lanes.json` (built and tested in P0.1) rather than a
  new `runtimes.toml`; only budget/execution config moved to `audit.default.toml`. A
  `comparison-sets` config is deferred to its consuming slice (P0.6) — YAGNI until then.
- Live provider execution is intentionally absent: the live path passes the safety gates
  and then refuses because probes arrive in P0.4. This slice proves the gates, not calls.
